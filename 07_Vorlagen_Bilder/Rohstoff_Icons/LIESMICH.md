# Rohstoff-Icons

Gemalte Icons (KI-Bild, 3 Blätter), ausgeschnitten und freigestellt als `res_*.png` (128 × 128, durchsichtig). Im Spiel liegen sie unter `ui/`.

- **Blatt 1** (`blatt_1_grundrohstoffe.jpg`): Beeren, Fleisch, Holz, Stein, Gold, Metall (Erz), Faser, Leder
- **Blatt 2** (`blatt_2_spaetere_rohstoffe.jpg`): Fisch, Getreide, Knochen, Honig/Salz, Kohle, Eisen, Öl, Uran, Energie, Münzen, Wolle, Bevölkerung
- **Blatt 3** (`blatt_3_krieg_industrie.jpg`): Munition, Schießpulver, Salpeter, Zinn/Kupfer, Stahl, Treibstoff, Ersatzteile, Sanität, Gummi, Glas, Aluminium, Mikrochip

Im Spiel benutzt (V2.20): Nahrung = `res_beeren.png`, Holz, Stein, Gold, Leute = `res_bevoelkerung.png`. Der Rest liegt bereit für spätere Epochen.
