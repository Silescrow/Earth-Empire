# SILES EMPIRE (früher Earth Empire)

Echtzeit-Strategie fürs Handy im Browser: Führe dein Volk von der Steinzeit bis in die Zukunft. Hier liegen alle Dateien, die das Spiel benutzt, und alle Spielversionen.

**Online spielen:** https://silescrow.github.io/SilesEmpireGithub/

| Ordner | Inhalt |
|---|---|
| `01_Hauptmenue` | `hauptmenue.jpg`, `ladebildschirm.jpg` (fürs Spiel) und die Originale `hauptmenue_original.png`, `ladebildschirm_original.jpg` |
| `03_3D_Modelle` | nach Epochen sortiert: `01_Steinzeit/` bis `10_Zukunft/` (eine Nummer je Epoche) und `99_Reserve/`, darin nach Art (Gebäude, Zäune, Figuren, Waffen, Tiere, Natur, Deko, Wasser, Schiffe). Spiel-Fassung + Meshy-Original in `Original/` (große Originale in Teilen, siehe `03_3D_Modelle/LIESMICH.md`) |
| `04_Musik` | `audio.js`: Musik und Geräusche, `crowns_upon_the_horizon.mp3` (Menü), `before_the_written_word.mp3` (Spiel), `LIESMICH.md` |
| `05_Geraeusche` | Liste aller Spielgeräusche (`LIESMICH.md`) |
| `06_Texte` | `Spielplan.md`: Zeitalter, Regeln, Steuerung und Reihenfolge |
| `07_Vorlagen_Bilder` | `Bild-Prompts.md`, `weltkarte_landmaske.png` und Vorlagenbilder; in `Werkzeuge/` die Hilfsprogramme (Weltkarte erzeugen, Modelle verkleinern, Einzeldatei bauen) |
| `08_App` | App-Symbole und `manifest.webmanifest` für die installierte App |
| `09_Alt` | alte Earth-Empire-Bilder in `Earth_Empire_Bilder/`; nicht mehr benutzte Dateien: `Baeume_alt/` (alte Meshy-Bäume mit Originalen) – siehe `09_Alt/LIESMICH.md` |
| `10_Alle_Versionen` | alle Spielversionen ab `V1.00`, fortlaufend nummeriert (+0.01 pro Version); die neueste läuft online als `index.html` im Repository `SilesEmpireGithub` |

Zum Spielen reicht die neueste Datei in `10_Alle_Versionen` – alle Bilder sind dort eingebaut.
