# EARTH EMPIRE

Echtzeit-Strategie fürs Handy im Browser: Führe dein Volk von der Steinzeit bis in die Zukunft. Hier liegen alle Dateien, die das Spiel benutzt, und alle Spielversionen.

**Online spielen:** https://silescrow.github.io/EarthEmpireGithub/

| Ordner | Inhalt |
|---|---|
| `01_Hauptmenue` | Ladebildschirm und Hauptmenü-Hintergrund (Originale als PNG, fürs Spiel verkleinert als JPG) |
| `02_Einheiten` | Bilder der Einheiten aller Zeitalter (noch leer) |
| `03_3D_Modelle` | `Steinzeit/`: Häuser, Zäune, Bäume, Busch als GLB (fürs Handy verkleinert) |
| `04_Musik` | `audio.js`: selbst erzeugte Musik und Geräusche, `LIESMICH.md` |
| `05_Geraeusche` | Liste aller Spielgeräusche (`LIESMICH.md`) |
| `06_Texte` | `Spielplan.md`: Zeitalter, Regeln, Steuerung und Reihenfolge |
| `07_Vorlagen_Bilder` | `Bild-Prompts.md`, `Weltkarte_Landmaske.png` und Vorlagenbilder |
| `08_App` | App-Symbole und `manifest.webmanifest` für die installierte App |
| `09_Alt` | nicht mehr benutzte Dateien |
| `10_Alle_Versionen` | alle Spielversionen ab `V1.00`, fortlaufend nummeriert (+0.01 pro Version); die neueste läuft online als `index.html` im Repository `EarthEmpireGithub` |

Zum Spielen reicht die neueste Datei in `10_Alle_Versionen` – alle Bilder sind dort eingebaut.

## Stand

Aktuell: **V1.06** – Steinzeit auf der echten Weltkarte (4 Größen, bis zu 18 Zivilisationen an ihren echten Orten), realistischer Boden mit Wüsten, Gebirgen und Schnee, Wasser mit Wellen, Herauszoomen bis zur ganzen Welt, Wappen-Fahnen, deine Meshy-Modelle, Höhlenmenschen mit Skelett, Palisade zum Selbstbauen, wehende Fahnen, eigene Musik und Geräusche.
